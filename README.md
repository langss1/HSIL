# HSIL Attendance App

A modern Flutter attendance application with geolocation validation, face capture, and a premium Admin Dashboard for HRD monitoring and reports.

## Kredensial Akses Admin

Gunakan akun berikut untuk masuk ke **Admin Dashboard**:

- **NIK / Username:** `0123456789`
- **Password:** `admin1`

*(Catatan: Akun ini dikonfigurasi secara otomatis memiliki peran 'admin' di database Firestore).*
